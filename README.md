# SG Routes

Running route planner for Singapore. Draw or trace routes on a map and track distance, elevation, terrain and which ones you've run.

- **Crew version:** https://kevinlimdesigns.github.io/Running-Dashboard/
- **Solo version:** https://kevinlimdesigns.github.io/Running-Dashboard/solo/

Routes are saved in your own browser only. Nobody else can see them. Use export / import to back them up or move them between devices.
